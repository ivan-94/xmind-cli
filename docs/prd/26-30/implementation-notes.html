README and CLI Help Polish Implementation Notes

本文件记录 GitHub issues #26-#30 的交付决策、偏差、权衡和未决问题。 它是 deliver-prd 期间父 Agent 与 slice worker 共用的轻量实现笔记， 不是公开 README，也不扩展 Source Manifest 的适用范围。

Current Decisions

  • 本轮没有独立父 PRD issue；以用户请求作为临时父目标， GitHub issues #26-#30 作为 confirmed slices。
  • README 层支持英文和中文：README.md 为英文主入口， README.zh-CN.md 为中文入口，二者互链。
  • CLI help 只使用英文，避免终端输出过长；中文说明放在中文 README 和文档入口中。
  • 裸 xmind 和 xmind --json 无子命令时都按 help 场景处理：向 stdout 打印顶层 help，退出码为 0。
  • Source Manifest 在本仓库只用于 PRD、issue、HAT artifacts 和 explicit handoff documents；README、overview、product docs、command references 和 implementation notes 默认不加。

Known Drift From Initial Issue Text

  • 创建 issues 时本地 checkout 落后远端，误判根目录没有 README.md。实际交付基线为 origin/master， 其中已有英文 README，但该文件仍含 Source Manifest，且缺少中文版本。
  • 本轮父分支从 origin/master 创建，不基于落后的本地 master。

Validation Plan

  • CLI 行为变更优先用测试锁定，包括空 invocation 行为和 help snapshots。
  • 文档变更通过人工检查、链接路径检查和现有 doc example 测试验证。
  • 整体交付门禁优先运行： PATH=/opt/homebrew/opt/rustup/bin:$PATH ./scripts/quality-gate.sh。

Slice #26 README Entrypoints

  • 英文 README.md 已调整为公开入口，不再承载交接清单； 中文 README.zh-CN.md 作为等价实用入口并与英文版互链。
  • 旧的 README 文档测试曾要求公开 README 包含交接清单；本 slice 将该检查改为锁定无交接清单、双语互链和 0.1.0 / Unreleased 的早期发布姿态。

Slice #27 Overview Links

  • docs/examples/README.md 被纳入本 slice，因为它是 examples 目录的人类入口页，且已有文档测试把它作为公开入口示例来源；清理范围仍限制在 README/overview 类页面。
  • 可复制命令代码块中的路径保持原样，避免把 CLI 输入改成不可执行的 Markdown 链接；导航列表和说明文字中的有效文件/目录引用改为链接。

Slice #29 CLI Help Examples

  • CLI help 继续保持英文-only；顶层 help 只放 4 个代表性 examples， 分别覆盖 read、search、dry-run write 和 export workflow，避免把 reference docs 的长语义搬进终端输出。
  • 每个子命令 help 补充一句 purpose、关键参数短说明和至少一个可复制 example；set、patch、import 保留 3 个 examples 来覆盖更复杂的使用分支。
  • diff 的 help 文案按当前 docs/reference/commands/diff.md 保持为 single-workbook diff surface，没有描述成 restore backup diff。
